# Система складского учета

Система складского учета предназначена для автоматизации процессов учета товаров на складе. Программа позволяет вести инвентаризацию, отслеживать поступления и списания товаров, а также генерировать отчеты.
## Описание

Система складского учета предназначена для упрощения процессов управления складом. Она поддерживает следующие функции:

- Учет товаров на складе.
- Ведение истории поступлений и списаний товаров.
- Генерация отчетов по товарам на складе, а также по операциям с ними.
- Удобный графический интерфейс на основе WPF.

## Требования

Для работы программы необходимы следующие компоненты:

- **.NET Framework 4.7.2** или выше.
- **Visual Studio 2019** или выше для сборки и модификации проекта.
- **SQL Server** для работы с базой данных.
- Установленные следующие NuGet пакеты:
  - `System.Data.SqlClient`
  - `Microsoft.EntityFrameworkCore.SqlServer` (если используется Entity Framework)


## Установка

1. Клонируйте репозиторий на ваш компьютер:
   ```bash
   git clone https://github.com/ваш-репозиторий/складское-учет.git
   ```

2. Откройте проект в **Visual Studio**:
   - Запустите Visual Studio и откройте решение проекта (`.sln` файл).

3. Настройка подключения к базе данных:
   - Убедитесь, что у вас установлен **SQL Server**.
   - В файле **App.config** (или **Settings.config**) укажите строку подключения к вашей базе данных SQL Server:
   ```xml
   <connectionStrings>
     <add name="ConnectionString" connectionString="Server=localhost;Database=WarehouseDB;Trusted_Connection=True;" />
   </connectionStrings>
   ```
5. Соберите и запустите приложение через Visual Studio.

## Использование

### Добавление товара

Для добавления нового товара в систему используйте форму **"Добавить товар"** в графическом интерфейсе приложения. Укажите название товара, количество и цену, затем нажмите кнопку **"Добавить"**.

### Списание товара

Для списания товара, откройте форму **"Списание товара"**, укажите название товара и количество, которое нужно списать. После этого нажмите кнопку **"Списать"**.

### Просмотр отчета

Для просмотра отчета о текущем состоянии склада используйте форму **"Отчеты"**. Здесь можно увидеть список всех товаров на складе с их количеством и ценой.

## Технологии

- **C#** — основной язык программирования.
- **WPF** — для создания графического интерфейса пользователя.
- **SQL Server** — для хранения данных о товарах.
- **Entity Framework** (если используется) — для работы с базой данных через ORM.
- **Microsoft Excel** / **PDF** — для генерации отчетов.
